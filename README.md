# Elite Alpha — Plataforma de Desenvolvimento Masculino & Alta Performance

Repositório oficial da plataforma **Elite Alpha**, um ecossistema completo focado no desenvolvimento pessoal, mentalidade, disciplina, performance física e financeira para homens, estruturado em conjunto com as soluções educacionais da **Corebyte Academy**.

## 🚀 Estrutura do Projeto

O site foi desenvolvido com foco em alta conversão, design moderno em *Dark Mode* e navegação fluida, dividido nas seguintes seções:
- **Home:** Manifesto de impacto e pilares fundamentais (Mentalidade, Disciplina, Performance, Finanças e Controle Emocional).
- **Sobre:** A essência, os valores inegociáveis e a missão de resgatar a liderança e a honra do homem moderno.
- **Orientações Jurídicas:** Seção especializada e canal de atendimento reservado para apoio em casos de Divórcio, Alienação Parental, Falsas Acusações, problemas com advogados e direitos.
- **Curso Elite Alpha:** Grade curricular completa do Módulo 0 ao Módulo 9 (do zero à alta performance).
- **Cursos (Corebyte Academy):** Vitrine integrada de cursos e formação tecnológica e profissional ([Corebyte Academy](https://corebytetech.com.br/courses.html)).
- **Contato:** Canais de suporte, atendimento e comunidade exclusiva.

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 (Responsivo com Grid/Flexbox)
- JavaScript (Interatividade e validações)
- Git e GitHub (Versionamento de código)
